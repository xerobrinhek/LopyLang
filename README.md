# LopyLang

**LopyLang** — статически типизированный компилируемый язык программирования, созданный, чтобы быть быстрым, лёгким и удобным. Он сочетает в себе выразительность синтаксиса Rust и понятную объектную модель Java, компилируясь в нативный код через LLVM.

## 🚀 Особенности

- **Гибкий синтаксис**: Java-стиль для классов, Rust-стиль для функций.
- **Нативная компиляция**: Компилируется в быстрый машинный код через LLVM.
- **Объектно-ориентированный**: Классы, поля, методы, конструкторы, инкапсуляция (`public`/`private`).
- **Простая система импорта**: `import mylib::*;` для подключения файлов и библиотек.
- **Базовые управляющие конструкции**: `if`, `while`, `for`.
- **Встроенный ввод/вывод**: `println(...)`, `input(int|string|bool)`.
- **Кроссплатформенность**: Работает на Linux, Windows и macOS.
- **Автономный компилятор**: Всё необходимое для работы встроено в сам компилятор.
- **Поддержка кириллицы**: Можно писать код на русском языке! (`функция`, `вывод`).

## ⚙️ Как это работает

1.  **Система кэширования**: При первом запуске компилятор создаёт папку `~/.lopy/` и скачивает необходимые библиотеки из GitHub-релиза.
2.  **Умный компилятор**: `lopy <файл.lp>` компилирует твой код, кэшируя промежуточные файлы (`.ll`, `.s`, бинарник) для ускорения повторной сборки.
3.  **Запуск**: `lopy <файл.lp> --run` скомпилирует и сразу запустит программу.

## 🛠️ Установка

### Сборка из исходников

1.  Клонируй репозиторий:
    ```bash
    git clone https://github.com/xerobrinhek/lopy-compiler.git
    cd lopy-compiler
    ```
2.  Собери компилятор:
    ```bash
    cargo build --release
    ```
3.  (Опционально) Добавь в `PATH` для удобства:
    ```bash
    sudo cp target/release/lopy /usr/local/bin/
    ```

### Системные зависимости (Linux)

Для работы компилятора и сборки библиотек на Linux потребуются следующие пакеты:

```bash
sudo pacman -S gcc clang llvm glfw-wayland glfw-x11 libx11 libxrandr mesa
```

## 📖 Пример кода

### На английском

```lopy
import llgui::Window;

fn main() {
    let window = new Window("LopyLang App", 800, 600);
    window.setTitle("LopyLang - Running!");
    window.clear(100, 150, 250);
    window.show();

    println("Главный поток завершился, но окно ещё живёт");
}
```

### На русском (кириллица!)

```lopy
функция привет() {
    вывод("Привет, мир!");
}

функция главная() {
    привет();
}
```

## 🧹 Управление кэшем

Чтобы очистить кэш компилятора, выполни:

```bash
lopy clean
```
