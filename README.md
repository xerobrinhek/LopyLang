# LopyLang

**LopyLang** — статически типизированный компилируемый язык программирования, созданный, чтобы быть быстрым, лёгким и удобным. Он сочетает в себе выразительность синтаксиса Rust и понятную объектную модель Java, компилируясь в нативный код через LLVM.

> ⚠️ **Статус: pre-alpha.** API может меняться. Баги приветствуются в Issues.
> Бинарников нет — компилятор собирается из исходников, LLVM ставится автоматически.

## 🚀 Особенности

- **Гибкий синтаксис**: Java-стиль для классов, Rust-стиль для функций.
- **Нативная компиляция**: Компилируется в быстрый машинный код через LLVM.
- **Объектно-ориентированный**: Классы, поля, методы, конструкторы, инкапсуляция (`public`/`private`).
- **Простая система импорта**: `import mylib::*;` для подключения файлов и библиотек.
- **Базовые управляющие конструкции**: `if`, `while`, `for`.
- **Встроенный ввод/вывод**: `println(...)`, `input(int|string|bool)`.
- **Пакетный менеджер**: `lopy.toml`, зависимости, `lopy install`.
- **Кроссплатформенность**: Нативно работает на **Linux** и **Windows** (x86_64).
- **Автоустановка тулчейна**: Компилятор сам скачивает LLVM для вашей ОС при первом запуске — ничего не надо ставить руками.
- **Поддержка кириллицы**: Можно писать код на русском языке! (`функция`, `вывод`).
- **UTF-8 в консоли**: Русский текст корректно выводится и на Windows.

## ⚙️ Как это работает

1. **Система кэширования**: При первом запуске компилятор создаёт папку `~/.lopy/` и скачивает LLVM в `~/.lopy/bin/llvm-mingw-<версия>/`.
2. **Умный компилятор**: `lopy <файл.lp>` компилирует твой код, кэшируя промежуточные файлы (`.ll`, `.o`, бинарник) для ускорения повторной сборки.
3. **Запуск**: `lopy <файл.lp> --run` скомпилирует и сразу запустит программу.
4. **Пакеты**: Зависимости описываются в `lopy.toml`, устанавливаются через `lopy install`.

## 🛠️ Установка

### Сборка из исходников

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/xerobrinhek/LopyLang.git
   cd LopyLang
   ```
2. Собери компилятор:
   ```bash
   cargo build --release
   ```

### Системные зависимости

**Linux:**
```bash
# Ubuntu / Debian
sudo apt install clang llvm

# Arch
sudo pacman -S clang llvm
```

**Windows:** ничего не нужно. Компилятор сам скачает `llvm-mingw` в `~/.lopy/bin/` при первом запуске.

## 📖 Примеры кода

### Hello, World!

```lopy
fn main() {
    println("Hello, World!");
}
```

### Переменные, типы и ввод

```lopy
fn main() {
    let name: string = input(string);
    let age: int = input(int);

    println("Привет, ", name, "! Тебе ", age, " лет.");
}
```

### Классы (Java-стиль)

```lopy
class Animal {
    public String name;
    private int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void speak() {
        println(this.name, " издаёт звук");
    }

    public int getAge() {
        return this.age;
    }
}

fn main() {
    let cat = new Animal("Барсик", 3);
    cat.speak();
    println("Возраст: ", cat.getAge());
}
```

### Циклы и условия

```lopy
fn main() {
    for (let i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            println(i, " — чётное");
        } else {
            println(i, " — нечётное");
        }
    }

    let n: int = 5;
    while (n > 0) {
        println("Осталось: ", n);
        n--;
    }
}
```

### Кириллица

```lopy
функция привет(имя: строка) {
    вывод("Привет, ", имя, "!");
}

функция главная() {
    привет("Артём");
}
```

### Импорты

```lopy
import llstd::math;
import mylib::*;

fn main() {
    let x = math::sqrt(16);
    println("Корень из 16 = ", x);
}
```

## 📦 Пакетный менеджер

Зависимости описываются в `lopy.toml`:

```toml
[package]
name = "my_awesome_app"
version = "0.1.0"

[dependencies]
llstd = "0.1.0"
mylib = "0.2.1"
```

Установка зависимостей:

```bash
lopy install
```

Пакеты скачиваются в `~/.lopy/packages/<имя>@<версия>/` и подключаются автоматически при компиляции.

## 🧹 Управление кэшем

Чтобы очистить кэш компилятора, выполни:

```bash
lopy clean
```
